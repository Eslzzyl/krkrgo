# Launcher UI Guidelines

本目录中的 launcher 面向多平台用户。所有用户可见内容和交互都必须保持跨平台一致，用户界面禁止出现特定操作系统、文件管理器或平台专属术语。

## 用户可见内容

- 菜单、按钮、标签、提示、对话框、状态消息、错误消息和帮助文案使用平台中立的表达。
- 文案中禁止出现特定平台的产品名称、文件管理器名称、路径格式、快捷键名称和窗口术语。
- 路径展示使用跨平台的简洁形式，表达项目含义和层级关系，不暴露操作系统专属格式。
- 同一操作在各平台提供一致的用户意图、入口和结果。平台差异由内部适配层处理。
- 中文和英文文案保持相同的语义范围，新增文案同步维护所有 launcher 本地化资源。

## 交互要求

- 菜单结构、按钮职责、确认流程、拖放行为、键盘操作和鼠标操作保持跨平台一致。
- 平台专属输入方式可以作为内部适配细节，用户可见提示使用通用描述。
- 文件选择、打开目录、窗口控制和系统集成采用通用用户语义，界面文案不能暴露底层平台实现。

## 内部实现

- 平台专属 API、路径处理、原生菜单调用、文件管理器调用、快捷键映射和构建标签可以存在于内部实现。
- 平台适配集中在现有抽象或清晰命名的辅助函数中，用户界面层依赖稳定的跨平台语义。
- 修改 launcher UI 时，同时检查可见文案、交互状态、本地化资源和不同平台的行为一致性。
